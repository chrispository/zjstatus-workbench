Custom command

zjstatus splits the command on spaces and honors quotes; it does not use a shell. Wrap pipes in bash -c '…'. Empty output hides the widget. An interval of 0 runs it once.

Icons

Battery reads /sys/class/power_supply on Linux and pmset on macOS. Load reads /proc/loadavg or sysctl. Kube context needs kubectl. Each hides itself when it has no output.

About

The Workbench generates a layout for zjstatus, the configurable status bar plugin for Zellij. Install the plugin at ~/.config/zellij/plugins/zjstatus.wasm, save the export to ~/.config/zellij/layouts/, and start Zellij with zellij --layout <name>.

Terminal palette mode exports ANSI indices (0–15), so the bar follows whatever theme your terminal uses. Fixed hex colors mode exports exact colors.

⣿ foreground ink stays transparent▓ solid fills are opaque

The browser simulates a translucent terminal; it isn't a screenshot. Glyph joins depend on your font and line height, so check the result at your real font size. Boxcar needs two content rows. Settings are saved in this browser only; Share link puts them in a URL, and every export embeds them so Import KDL can restore the exact bar.
